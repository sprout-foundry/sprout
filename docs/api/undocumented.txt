# Undocumented routes allowlist
#
# Every route registered in pkg/webui/routes.go must be documented in
# docs/api/openapi.yaml OR listed here, one mux pattern per line. A Go test in
# pkg/webui (TestOpenAPISpecCoversAllRegisteredRoutes) enforces this and fails
# if a route appears in neither file.
#
# This is a shrink-only allowlist: an entry is removed from this file the same
# change that documents its route in docs/api/openapi.yaml. A route that is
# documented in openapi.yaml must not also appear here — the test fails when it
# does, so the file can only lose entries over time.
#
# The pattern is written exactly as the mux.HandleFunc pattern is registered
# (a trailing "/" marks a prefix route; {name} is a Go 1.22 wildcard segment).
# Blank lines and lines starting with "#" are ignored.
#
# Until a route is documented in openapi.yaml it is kept here, so the skeleton
# ships with every registered route listed. The order is plain lexicographic so
# the file is stable and diffs stay readable as entries are removed.
