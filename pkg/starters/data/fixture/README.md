# Fixture starter

Minimal test-only starter that proves the SP-153 starter embedding and
instantiation mechanism (TODO 153.3, spec §153b). It is not a product
starter: the reference starters (static site, web app, web app with data)
ship in later items.

The files here exist so the embedded tree has real content — including a
nested directory — for the copy mechanism to move.

Build: `npm run build` · Test: `npm test` · Dev server: `npm run dev`
(port 3000) · Build output: `dist`.
